 # Custom Assembly Interpreter Project
  
**Description**: This is a project that involved the creation of a custom assembly language. This language can be typed out in a custom IDE with a custom assembler. The IDE also has an interpreter, built with Java, that can interpret the custom instructions and simulate the execution of this custom language.

**Specs**: As of version 1, the project involves over 2000 lines of code, spanning across +15 different classes. All aspects are from scratch, and no libraries were used outside of the Java Standard Library.
  
**Compatability**: This is designed to be used and run on MacOS. It may work on Linux and possibly even Windows, though some File Handlers might be setup for unix style file systems. Core functionality should be unaffected, and for this reason, I will include built distributions for all three operating systems. IF YOUR OPERATING SYSTEM IS NOT COMPATIBLE USE AT YOUR OWN DISCRESSION; IT MAY NOT WORK.
